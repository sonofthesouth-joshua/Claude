# AgenticOS Starter Kit — The 5-Step Install, DIY Edition

You booked the call. As promised: the five install skills, yours to run in your own business — whatever happens next.

This kit is a working, self-contained **AgenticOS vault**: the same five-step structure we install for clients, in a version you can run yourself with an AI coding agent. It is not a course and not a PDF. The five skills inside (welcome, brain-install, bottleneck-finder, skill-forge, system-health) carry you through the five steps — and by Step 4 you're controlling your own agents from a dashboard.

## What you need

- **An AI agent CLI** — [Claude Code](https://claude.com/claude-code) (recommended) or any agent CLI that can read files and follow markdown instructions (Codex CLI works too). A paid plan is strongly recommended: the Brain Install reads a lot of documents. **That's the only thing you install yourself** — the agent guides you through everything else, adapted to your machine.
- **Your company documents** — a folder (or Drive export) with the material your business runs on: offers, processes, client docs, anything a great new hire would be given.
- **2–4 hours for Step 1**, then roughly an afternoon per step. Steps checkpoint themselves — you can stop and resume anytime.

No Obsidian, no Notion, no coding knowledge required.

## How to start

**Starting from zero** (nothing installed, never used a terminal): follow **`guides/step-0-setup.md`** — 15 minutes from blank computer to running agent, no assumptions.

**Already have Claude Code?**
1. Put this folder somewhere permanent, e.g. `~/YourCompanyOS` (not in iCloud-synced folders like `~/Documents` — cloud sync breaks agent file access on macOS).
2. Open a terminal in this folder and run `claude`.
3. Say: **"Read AGENTS.md, then read and follow `000 OS/skills/welcome/SKILL.md`."**

The welcome skill checks your machine, fixes what's missing with you, and hands you into Step 1. From there the agent drives; you answer its questions.
